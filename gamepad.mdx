## Connecting

<Steps>
  <Step title="Connect your controller">
    Plug in via USB, or pair via Bluetooth in your device's system settings.
  </Step>
  <Step title="Open SkillTanki in the mobile PWA">
    Navigate to [https://mobile.skilltanki.workers.dev/](https://mobile.skilltanki.workers.dev/) or launch the installed PWA from your home screen.
  </Step>
  <Step title="Start playing">
    The game automatically detects the first connected controller. No in-game configuration screen, no button remapping required — just pick up and play.
  </Step>
</Steps>

<Note>
  Nothing to configure. The game picks up the first connected controller automatically.
</Note>

## How inputs interact

All three input methods — touch, keyboard, and gamepad — work simultaneously, and the game switches between them fluidly:

- **Touch the controller:** on-screen buttons fade away so they don't clutter the display
- **Touch the screen:** on-screen buttons reappear immediately
- **In menus:** D-pad and left stick move focus between options; **✕** confirms, **○** cancels — just like a standard controller UI

You can start a session on touch and pick up a controller mid-game, or use touch to navigate menus and a gamepad to play — everything works together without any mode switching.

## Steam Deck notes

The Steam Deck's built-in controls map directly to the standard gamepad layout, so the game works without any special configuration. No community controller layout or extra setup is needed — connect and play.
